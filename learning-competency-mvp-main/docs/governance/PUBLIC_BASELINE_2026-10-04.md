# LASTRO Public Baseline — 2026-10-04

## Status

**PUBLIC BASELINE / MAINTENANCE MODE**

The current LASTRO public repository is considered structurally complete for the present MVP/documentation cycle.

This is a freeze of the current public baseline, not an archival shutdown.

## Frozen scope

The public repository currently contains the reproducible product and technical surface required for the present MVP:

- implementation and tests;
- canonical product and architecture documentation;
- synthetic evidence fixtures;
- reproducible demo contracts;
- bounded public research;
- verification and attestation implementation;
- public governance and publication boundaries.

## Maintenance policy

After this baseline:

1. bug fixes may be made when necessary;
2. reproducibility failures may be corrected;
3. submission/demo-critical corrections may be made;
4. security or dependency fixes may be made when justified;
5. architectural expansion should not be added merely to keep the repository active.

New experimental agent architecture is developed outside this public repository unless and until it becomes a justified, reviewed dependency of LASTRO.

## Authority boundary

The public repository remains the canonical source for current public implementation and reproducible project claims.

Private operational architecture, experimental agent infrastructure, and internal working knowledge remain outside this repository.

## Review principle

The objective is now to preserve a coherent, auditable baseline rather than continuously expand scope.
