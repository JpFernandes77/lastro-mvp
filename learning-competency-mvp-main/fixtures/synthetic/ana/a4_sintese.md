# Síntese para a coordenação

**Público:** coordenação de operações.

## Conclusão
O aumento do TMA está concentrado no canal telefone e acompanha o crescimento dos chamados escalados ao 2º nível (12% → 21%). O turno teve efeito pequeno.

## Evidências utilizadas
Tabela de TMA por canal/mês e modelo linear do notebook de análise (a3_analise.ipynb), com dados sintéticos de jun–ago.

## Limitações
A análise mostra associação, não causalidade. Não há dados sobre a complexidade real de cada chamado nem sobre mudanças de equipe no período.

Investigar os motivos de escalonamento no telefone com uma amostra de chamados.
